SeaGuard HeatWatch · 3-minute judge guide

Heat-stress early warning for port and offshore workers in Abu Dhabi. Machines detect, fixed rules recommend, AI only explains: a person always decides.

Click a step: each opens the right screen, already set up. No sign-in needed. Use the top bar to come back here.

📂 Source code and README on GitHub · Backup demo links: Google Cloud Run · Microsoft Azure (Azure may take about 30 s to wake up)
